# 역사 탐정사무소 v4.9

중학교 3학년 한국사 수업용 역사 탐정 활동 웹앱입니다.

## 구성
- `index.html` : 메인 탐정사무소
- `case_data/` : 44개 사건 데이터
- `stamps/` : 44개 사건 스탬프
- `assets/office-bg.png` : 탐정사무소 배경

## 수록 범위
1. 선사 문화와 고대 국가의 형성 — 7개 사건
2. 남북국 시대의 전개 — 7개 사건
3. 고려의 성립과 변천 — 8개 사건
4. 조선의 성립과 발전 — 7개 사건
5. 조선 사회의 변동 — 7개 사건
6. 근현대 사회의 전개 — 8개 사건

총 44개 사건입니다.

## GitHub Pages 배포
저장소 루트에 `index.html`, `case_data`, `stamps`, `assets`가 보이도록 업로드합니다.
GitHub 저장소의 Settings > Pages에서 main 브랜치의 root를 배포 대상으로 지정하면 됩니다.

## 주의
- 폴더 구조를 변경하지 마세요.
- 사건 진행 및 스탬프 상태는 브라우저 `localStorage`에 저장됩니다.
- 다른 브라우저나 다른 기기에서는 기존 진행 기록이 자동으로 공유되지 않습니다.
