# 역사 탐정사무소 최종본

최종 정리일: 2026-10-14

## 구성
- index.html: 학습지 연계 구조 + 아이콘 수정 최종본
- assets/: 탐정사무소 배경 및 UI 아이콘
- case_data/: 기존 선택형 추가 사건 44개
- stamps/: 기존 추가 사건 스탬프 44개
- source_data/: 학습지 연계 필수 사료 수사 31개
- source_stamps/: 필수 사건 스탬프 31개
- .nojekyll: GitHub Pages 설정

## 현재 수업 구조
- 1~5단원: 학습지 1개 = 필수 역사탐정 사건 1개
- 같은 학습지 주제의 기존 사건은 선택 추가 사건
- 6단원: 학습지 제작 전이므로 기존 사건 8개를 순서대로 제공
- 탐정수첩: 필수 사건 스탬프 중심 + 선택 추가 사건 보너스 스탬프
- 필수 진행률: 1~5단원 31개 + 6단원 기존 8개 = 39개
